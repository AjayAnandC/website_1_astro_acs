# Astrology Booking Website

A responsive website built for an astrology business offering profiles, appointment booking, and subscription-based daily/weekly/monthly reports.

## Features

- Mobile-first responsive design
- User profile creation and login
- Appointment booking system
- Subscription plans with report generation
- Dashboard with profile, appointments, and reports

## Run locally

1. Open `index.html` directly in a browser, or
2. Run a static server in this folder:

```bash
cd f:\Projects\Website_1
npx serve
```

## Project structure

- `index.html` — website markup
- `css/styles.css` — responsive styling
- `js/app.js` — profile, booking, subscription, report logic
- `astrology.agent.md` — custom agent instructions
- `astrology.skill.md` — astrology website skill guidance
